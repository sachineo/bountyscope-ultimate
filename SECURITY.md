# Security Policy

## Supported version

Security fixes currently target the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public GitHub issue for a security vulnerability.

Send a private report to the repository owner through the contact method listed on the [Sachin GitHub profile](https://github.com/sachineo) or [skoolic.com](https://skoolic.com).

Include:

- The affected component and version
- Clear reproduction steps
- Expected and observed behavior
- Security impact
- A safe proof of concept using only researcher-controlled data
- Any suggested remediation

Do not include live credentials, third-party personal data, or data obtained without authorization.

## Research boundaries

BountyScope is built for authorized research. Vulnerability reports must use owned systems, controlled labs, or targets where the reporter has explicit testing permission.
